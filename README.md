# Diabetes-Risk-Prediction-Using-Deep-Learning

This project applies deep learning techniques to predict diabetes risk based on health and lifestyle data.  
Developed using Python (TensorFlow, Keras, Pandas, NumPy) with data preprocessing, feature scaling and model evaluation.  
Achieved high accuracy and F1-score in predicting diabetes risk using neural network architectures.
